# Product Requirements Document (PRD)
## 제품명: Driver-Go ETA System (가칭)

### 1. 배경 및 목표 (Background & Goals)
물류/배송 업계에서 장거리 트럭 운전사의 위치와 예상 도착 시간(ETA)을 수동으로 보고받는 과정은 비효율적이며 정보의 지연 및 오류를 발생시킵니다. 
본 프로젝트의 목표는 드라이버의 개입 없이 **실시간 GPS 기반으로 정확한 ETA를 자동 산출하고, 수신자와 관리자에게 배송 현황을 투명하게 제공**하는 시스템을 구축하는 것입니다.

### 2. 핵심 타겟 사용자 (Target Audience)
* **트럭 드라이버 (Driver):** 운전 중 조작을 최소화하고 길안내를 받아야 하는 장거리 운전자.
* **플릿 매니저/디스패처 (Admin):** 수십~수백 대의 트럭 운행 상태를 실시간으로 모니터링하고 예외 상황(지연 등)에 대응하는 관리자.
* **수신자 (Recipient):** 물품을 받을 고객사나 창고 담당자로, 앱 설치 없이 실시간 도착 정보를 확인하길 원함.

### 3. 사용자 스토리 (User Stories)
* **드라이버:** 
  * "나는 운전 중에 번거로운 조작 없이, 원클릭으로 운행을 시작하고 길안내를 받고 싶다."
  * "나는 운전 중 앱 화면을 보지 않고도, 주요 알림을 소리나 진동으로 인지하고 싶다."
* **관리자 (Admin):**
  * "나는 전체 트럭의 실시간 위치를 지도 한 화면에서 보고 싶다."
  * "나는 정체나 사고로 인해 지연이 예상되는 배송 건만 필터링해서 우선적으로 확인하고 싶다."
* **수신자:**
  * "나는 트럭이 도착하기 30분 전에 SMS 문자로 알림을 받고 싶다."
  * "나는 문자의 링크를 클릭해 트럭의 현재 위치를 지도에서 바로 보고 싶다."

### 4. 기능 스코프 (MVP Scope)
**In-Scope (Phase 1):**
* 드라이버 앱: GPS 백그라운드 수집, 하이브리드 네비게이션 연동, 스와이프 상태 변경
* 수신자 웹: 임시 URL 기반의 실시간 트럭 마커 트래킹
* 관리자 대시보드: 기초 노코드 툴(Supabase/Retool) 연동을 통한 데이터 모니터링
* 알림 시스템: 출발/도착 SMS 알림

**Out-of-Scope (Future Phases):**
* 머신러닝 기반 ETA 보정 (Phase 3)
* 드라이버 운전 패턴 분석 스코어카드 및 리워드 기능
* 자체 관리자용 커스텀 관제 대시보드 (Phase 2)

### 5. 성공 지표 (Success Metrics)
* **가동률:** 드라이버의 앱 백그라운드 GPS 수집 성공률 95% 이상 유지.
* **업무 효율:** 관리자의 드라이버 위치 확인 목적 전화 통화량 80% 감소.
